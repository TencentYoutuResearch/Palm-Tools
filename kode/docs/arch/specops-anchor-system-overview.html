SpecOps × Anchor System Architecture

集中控制面 · 分布式执行面 · 独立验证面 · 可追溯 Proof / Decision 闭环

产品与协作

  • • 研发留在 kode / SpecOps，其他角色使用 Anchor 或既有系统
  • • 所有入口操作同一个 Delivery、Proof 与 Decision 时间线
  • • 正常步骤自动推进，异常才进入角色 Inbox

执行与调度

  • • 控制面集中，Runner 分布在代码、设备与 secrets 所在环境
  • • Product Profile 提供模板，Step Capability 决定真实调度
  • • 实现 Runner 与 Verifier Runner 可独立，避免同环境自证

信任与数据

  • • Human / Agent / Policy Principal 的授权与签署分别留痕
  • • 控制面默认保存 metadata 与 evidence index，内容按策略上传
  • • Repair 会使受影响 Evidence stale，并只重跑必要步骤
