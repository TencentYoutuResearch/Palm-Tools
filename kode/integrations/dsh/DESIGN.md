# Builder surface design contract
The existing DSH/Kode session is the visual authority. This is an Operate surface.
- One conversation canvas beneath the existing application sidebar, with the native composer at the bottom.
- Team Builder is an ordinary-looking row in the existing private-message section, without a new system category.
- History is an on-demand native menu. Preparation and design details occupy the main content area only when requested, following the existing settings hierarchy; no permanently visible engineering sidebar.
- A saved goal appears once as user-authored text, with a short thread title. Long original text is expandable and never rewritten.
- Before runtime starts, show an honest preparation state and a single next action. Do not render a questionnaire as an assistant reply.
- Use native DSH Menu, Button, Input, UserTextRun, MarkdownText and the existing PortableTextComposer. Retain native font, spacing and color tokens. No decorative motion.
- Existing completed configuration is read and summarized; only the current incomplete step is shown. Budget means an internal usage limit, not a payment.
