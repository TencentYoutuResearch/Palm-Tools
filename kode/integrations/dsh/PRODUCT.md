# Kode collaboration UI
<!-- impeccable:product-schema 1 -->
## Platform
web
## Product Purpose
Help the owner design and operate teams through existing Kode direct messages and DSH conversation controls.
## Capabilities and Constraints
User-confirmed direction: Team Builder belongs in the existing private-message list. Preserve the current workspace, saved design drafts, unsent input, native Agent/model controls, and explicit authority/budget confirmations. Do not fabricate model messages, infer execution authorization from conversation, or start an unsafe runtime.
## Brand Commitments
Preserve Kode Orbit and the original DeepSeek Harness identities. Use the existing Kode session and settings hierarchy, not a new design system.
## Open Decisions
Backend runtime readiness is authoritative and must not be inferred from visual state.
