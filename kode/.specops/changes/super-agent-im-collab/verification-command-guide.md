# 本机验证命令入口（隔离开发版本）

入口已在工作树实现；没有安装到日常 dsh 环境。此说明不代表整个 Superagents 方案验收完成。

1. 切换 IM，打开「团队搭建助手」，创建或继续团队草案，并选定当前 Host 上的工作区。
2. 展开「配置本机验证命令」。输入执行器/命令标识、不可变版本、可执行文件绝对路径、参数 JSON 数组、场景、超时和输出上限；按项目需要明确写入工作区和网络权限。环境变量固定为空。
3. 点击「核对验证命令」。Host 返回实际文件路径、内容指纹、参数、场景和权限供核对。此步不登记、不执行；可「返回修改」。
4. 点击「确认登记此命令」。若结果不确定，使用「恢复原命令登记」；刷新草案后原确认会从浏览器存储恢复。不要把未确认的请求改成另一条命令。
5. 登记成功后，告诉创建助手使用该命令身份，例如「用 local / smoke / 1 作为验证命令」。助手通过已有只读目录工具获得实际引用及环境指纹，继续生成工作流和项目绑定供核对。

登记不激活团队，也不授予执行权限。执行仍需已激活版本、当前授权、资源与预算准入，并重新核验文件指纹。修改参数或文件后须核对新的不可变版本；既有版本不覆盖。相同确认可恢复已提交结果，不能用该回执宣称命令已执行或验证通过。

当前入口只配置当前 Host 的本机命令；远端登记和跨 Host 配置不在本入口的已验收范围。单独的登记/恢复、原生 Builder 引用读取已有测试；从全新资源配置到首次实际交付的整条桌面路径仍待验收。
